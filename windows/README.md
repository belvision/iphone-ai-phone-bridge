# GAEV Call Assistant

[English](README.en.md)

Экспериментальный помощник для телефонных разговоров на Windows 11. Приложение отслеживает состояние звонка iPhone через Windows Phone Link и передаёт звук между звонком и голосовым агентом ElevenLabs с помощью VB-CABLE. Сценарии на русском редактируются в приложении. История сеансов и расшифровки сохраняются локально.

## Быстрый старт

1. Установите .NET 10 SDK и VB-CABLE. Подключите iPhone по Bluetooth в приложении «Связь с телефоном». Убедитесь, что в нём доступны вызовы.
2. Выполните из каталога исходников `dotnet run --project GaevAssistant.csproj`. Для сборки отдельного Windows x64-файла выполните `powershell -ExecutionPolicy Bypass -File build.ps1`.
3. В настройках укажите собственный API-ключ ElevenLabs и ID настроенного голосового агента. Ключ хранится в локальном хранилище Windows DPAPI. На вкладке сценариев проверьте и примените подходящий текст.
4. Включите ожидание. Когда приложение покажет готовность, выполните пробный вызов со своего телефона через Phone Link. Проверьте звук в обе стороны.

Для работы с телефонной линией и звуком требуются совместимые телефон, адаптер и драйверы Windows. Приложение рассчитано на звонки, в которых участники уведомлены об использовании голосового ИИ. ElevenLabs обрабатывает передаваемый звук, поэтому проверьте настройки своего агента и хранения данных.

В репозитории только исходники общей версии. Локальная база контактов, история, ключи и персональная интеграция с чатом GAEV не входят в поставку.
