Экспериментальный аудиомост iPhone / Windows / Retell

Обновление 15.10.2026 — сравнение трёх вариантов:
- Retell сохранён как вариант по умолчанию; настройка и ключ не меняются.
- «ElevenLabs Agents» — закрытый русскоязычный агент ElevenLabs. Наш мост
  управляет началом после ответа, PCM, перебиваниями и завершением звонка.
- «Свой диалог» — Scribe v2 realtime → DeepSeek v4 Flash → ElevenLabs Flash.
  Ответы идут потоком и озвучиваются по коротким фразам; при перебивании
  отменяются запросы модели/озвучки и очищается очередь старого голоса.
- Поля «Первое сообщение» и «Инструкция помощнику» доступны для обоих
  вариантов ElevenLabs. «Сохранить инструкцию агента» обновляет также
  облачного агента. В каждом его разговоре мост передаёт актуальную
  инструкцию, русский язык и приветствие через защищённые overrides.
- У готового агента включены interruption events, прерываемое приветствие
  и eager turn-taking. В своём диалоге ~100 мс речи абонента отменяют
  генерацию и очередь звука; короткая пауза не завершает реплику.
  Пауза после речи регулируется от 250 до 1500 мс, по умолчанию 350 мс.
  Измерения 1.66–2.39 с в JSON сделаны с предыдущей паузой 450 мс.
- В обоих новых вариантах нет CRM, клиентских инструментов и локальной
  записи разговоров/транскриптов. Обработка и хранение у провайдеров зависят
  от настроек их аккаунтов. Ключи ElevenLabs/модели хранятся в
  %LOCALAPPDATA%\RetellPhoneBridge\eleven.dpapi с Windows DPAPI.
  HTTP GET настроек возвращает только признаки наличия ключей.
- DeepSeek работает напрямую, ElevenLabs — через тот же прокси США.
- Чтобы сменить вариант: «Остановить» → нужная кнопка сервиса →
  при необходимости «Настройки подключения» → «Включить помощника».
  Набирать/принимать звонок нужно по-прежнему через «Связь с телефоном».
- Замеры на синтетической русской фразе, без звонка: Agents 0.96–1.44 с,
  свой диалог 1.66–2.39 с от конца фразы до первого звука. Были также
  сетевые ошибки собственного диалога; стабильность требует живого теста.
  Это небольшая выборка с разными голосами/моделями, не гарантия задержки.
  Полные измерения и методика: latency-results.json.
- Локальный Whisper small на CPU проверен: 2.29–2.62 с распознавания
  при beam=1 плюс ожидание конца фразы; Scribe после ручного commit — 0.37 с.
  Поэтому Whisper пока оставлен для сравнения, в рабочую цепочку не включён.
- Codex Astra CLI проверен: 12.5–13.8 с на короткий ответ при обычном
  запуске; с явно указанным прокси США ответ не пришёл за 45 с.
  Для собственных звонков выбран DeepSeek, без доступа модели к файлам,
  инструментам Codex и командам компьютера.
- Marina через API недоступна бесплатному аккаунту (HTTP 402).
  В своём диалоге для проверки используется встроенный голос Sarah;
  у готового агента — Eric/V4 Turbo. Подписка и автопополнение не менялись.
- Новые варианты протестированы на синтетическом аудио. Звук через

Адрес в вашей Opera: http://localhost:8766

Выбор передачи звука — в свёрнутом блоке «Способ передачи звука»:
- «Нынешний способ» — прежний WDM-KS выход напрямую в iPhone. Работает,
  но в последних тестах потерял примерно 10% аудиоданных на выходе.
- «Виртуальный микрофон» — Retell → WASAPI CABLE Input 48 кГц стерео →
  CABLE Output как микрофон Windows → Phone Link → iPhone. Это отдельный
  реализованный маршрут, без прямой записи в скрытый HFP endpoint.
  Качество ещё не подтверждено реальным звонком.
- До включения виртуального режима установить официальный VB-CABLE,
  перезагрузить Windows, запустить start.ps1 и открыть localhost:8766.
  Установленный оригинальный пакет: vendor/vb-cable-pack45.
  Цифровая подпись VBCABLE_Setup_x64.exe проверена: Valid, BUREL VINCENT.
  Установка подразумевает согласие с лицензией из оригинального readme.txt
  и требует прав администратора; без подтверждения владельца не запускается.
- Выбрать виртуальный режим до звонка и нажать «Включить помощника».
  Программа временно ставит CABLE Output микрофоном Windows для всех ролей.
  Другие приложения также могут получать голос агента вместо физического микрофона.
  Динамики Windows должны оставаться обычными, иначе возникает аудиопетля.
- «Остановить», закрытие страницы, потеря heartbeat на 30 секунд и штатное
  завершение сервера восстанавливают предыдущий микрофон. Резервная копия
  .mic-restore.json позволяет восстановиться после аварийного перезапуска.
  Если пользователь сам поменял микрофон, такое изменение сохраняется.
- Если Phone Link уже запомнила старый микрофон, может понадобиться заново
  открыть приложение перед новым звонком. Это проверяется живым тестом.
- SIP оператора и шлюз с SIM-картой описаны как будущие отдельные подключения;
  они пока не являются переключаемыми рабочими режимами этой программы.

Автоматический запуск на любые отвеченные тестовые звонки:
- Ввести Public Key, подтвердить предупреждение собеседника и нажать
  «Включить помощника». Затем набрать номер либо принять входящий через Phone Link.
- Оставить разговор на компьютере. Выключить музыку, видео и уведомления:
  вход мост получает из воспроизведения Windows (WASAPI loopback).
- Программа ждёт официальный статус Windows PhoneCall.Talking и звук на ПК.
  Во время гудков Retell не запускается. Подключение после ответа занимает
  несколько секунд. После нормального завершения Retell/сотового разговора
  ожидание следующего звонка остаётся включённым. Та же сессия
  сотового звонка повторно не запускает AI. Локальный лимит в 2 минуты снят:
  разговор продолжается до завершения звонка/сессии Retell или «Остановить».
  Вместо обратного отсчёта отображается прошедшее время разговора.
- Агент подключается и на входящих, и на исходящих, включая уже отвеченный
  разговор на компьютере при включении помощника. Сам сотовый вызов программа
  не принимает: входящий нужно принять обычным способом. Виртуальный микрофон
  нужно подготовить до начала разговора, чтобы Phone Link выбрала его входом.
- Краткий пропуск данных монитора до 3 секунд приостанавливает запуск,
  затем свежие данные позволяют продолжить ожидание. Одновременные несколько
  звонков не поддерживаются. Пропущенный между опросами конец предыдущего
  разговора больше не выключает ожидание следующего.
- «Остановить» выключает AI и ожидание, включая отмену во время очистки.
  Сотовый звонок завершается отдельно в «Связи с телефоном»/на iPhone.
- Публичный ключ и ID находятся в свёрнутых «Настройках подключения»;
  ручные тесты и технические сведения — в «Проверке звука и журнале».
- Ошибка Retell/аудиомоста, потеря состояния, несколько звонков, удержание
  и перевод звука на iPhone выключают помощника и ожидание. После устранения
  причины включить помощника вручную.
- Для этой функции используется локальный read-only монитор Windows Calls API,
  без управления интерфейсом Phone Link и без регистрации приложения в телефонии.
  Номера/имена/идентификаторы звонков не возвращаются в панель и не записываются.

Ручная проверка звука — в «Проверке звука и журнале»:
- Во время обычного звонка нажать «Проверить звук» и проверить индикатор речи.
- «3 тестовых сигнала» должен услышать собеседник на другом телефоне.
- «Подключить AI вручную» запускает один платный тест без режима следующих звонков.

Ограничения:
- Один звонок, только ручной набор. Автоматический обзвон и перевод не реализованы.
- AI не управляет «Связью с телефоном» и не завершает сотовый звонок.
- Выход Windows по умолчанию должен совпадать с выходом, где слышен Phone Link,
  и иметь формат 48000 Гц float32. Мост не меняет устройства Windows по умолчанию.
- На компьютере должен быть ровно один WDM-KS выход Hands-Free HF Audio.
- При смене телефона/адаптера/драйвера нужно заново проверить оба направления.
- Качество речи, задержка и устойчивость длительной работы ещё не оценены.
  В коротком тесте прерывания подтверждены, настройка буфера их не устранила.

Локальная программа слушает только 127.0.0.1:8766, проверяет Host и Origin,
разрешает одну сессию и останавливает аудио через 120 секунд/при закрытии вкладки.
Локальные записи звука не создаются. Public Key и ID агента автоматически
сохраняются в %LOCALAPPDATA%\RetellPhoneBridge\connection.dpapi, зашифрованном
Windows DPAPI для текущего пользователя. Подключение общее для Chrome и Opera
и загружается после перезапуска программы. Секретные API-ключи не принимаются.
Сохранение не создаёт звонок. Public Key отправляется Retell для WebCall.
Обработка/запись в самом Retell зависит
от настроек вашего агента. После нажатия подключения звук передаётся в Retell.

Сеть Retell:
- 15.10.2026 прямой запрос из Chrome вернул «Access from sanctioned region is
  not allowed». По поручению владельца взят основной прокси из локального
  web/sync_full/config.php. Страна выхода проверена через api.country.is: US.
  Резервный прокси на момент проверки не ответил.
- Учётные данные прокси сохранены только с Windows DPAPI в
  %LOCALAPPDATA%\RetellPhoneBridge\network.dpapi; в браузер не возвращаются.
- REST управления Retell и HTTP-сигналинг WebRTC проходят через локальный
  /retell/ и американский HTTP CONNECT прокси. Назначение фиксировано:
  api.retellai.com; разрешены только create-web-call, stop-call и gateway sessions.
  Проверка без настоящего ключа получила ожидаемый HTTP 401 за 0.74 секунды,
  без геоблокировки и без создания платного звонка.
- Медиатранспорт WebRTC выбирает сетевой маршрут средствами браузера;
  настройка HTTP-прокси не означает туннелирование UDP-медиа через него.
- Выбор аудиовыхода сделан кнопками «Через iPhone» / «Через VB-CABLE» и
  сохраняется вместе с подключением. Через прокси не открываются звонки,
  пока локальный сервер не подтвердит отвеченный разговор и готовый аудиомост.

Состав:
native_audio.py — WASAPI capture + KS output, FIR 48→16 кГц, ограниченные очереди.
audio_routes.py — выбор выхода и временный микрофон с восстановлением настроек.
audio_routes_test.py — локальные проверки преобразования, отката и HTTP-ограничений.
probe_virtual_route.py — реальная проверка VB-CABLE без Retell и записи звука.
native_server.py — локальный HTTP/WebSocket.
connection_store.py / connection_store_test.py — зашифрованное подключение и проверки.
retell_relay.py / retell_relay_test.py — ограниченный HTTPS relay через прокси США.
phone_state.py / probe_phone_state.ps1 — read-only монитор принятого звонка.
auto-call.js / auto-call.test.mjs — последовательный запуск и проверки переходов.
app-lifecycle.test.mjs — проверка жизненного цикла панели с заглушками без Retell.
browser-native.js / native-worklet.js — PCM ↔ MediaStream.
native-retell.ts — экспериментальный адаптер к SDK Retell 3.0.2 (ISC).
app-source.js / index.html — панель; npm run build собирает app.js.
probe_*.py / diagnose_audio.py — разовые диагностические проверки.
probe_ks_mute.ps1 — подготовленная, ещё не выполненная проверка конкуренции
  аудиопотоков; только с явным -RunLive и восстановлением исходного mute.
index.browser-only.html / app-source.browser-only.js — исходная браузерная версия.

После перезагрузки компьютера запустить start.cmd заново. Сохранённый публичный
ключ и ID агента подставляются автоматически в браузере этой учётной записи Windows.
Для остановки сервера: Ctrl+C в окне запуска. Автозапуск не установлен.
